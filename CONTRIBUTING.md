# Contributing to DIP

1. Open an issue describing the change before large work.
2. Branch from `main`. Keep changes focused.
3. Run `pnpm check` locally; it must pass.
4. Protocol-visible changes must update `docs/spec/` and add a conformance test.
5. Record non-obvious design choices in `docs/ARCHITECTURE_DECISIONS.md`.
6. Commits should explain why, not only what.
