# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems. Report privately through
GitHub Security Advisories on this repository (Security tab, "Report a
vulnerability"). Include affected components, reproduction steps and impact.

## Scope

Protocol design flaws, cryptographic misuse, authorization bypass, execution
boundary escapes, ledger tampering that verifies, and verifier false positives
are all in scope.

## Supported versions

Nothing is released yet. Only the default branch is supported.
