# Architecture Decisions

## ADR-0001: Monorepo with pnpm workspaces

Status: accepted. One repository holds spec, packages and docs so they version together.

## ADR-0002: Strict TypeScript

Status: accepted. `strict`, `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes` are on.

## ADR-0003: No dependency on Parmana

Status: accepted. DIP must operate and verify evidence standalone. Parmana integration is a later connector-level phase.

## ADR-0004: License Apache-2.0

Status: proposed. Chosen as a default; the owner must confirm.
